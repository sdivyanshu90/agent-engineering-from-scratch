# Week 7 — Bounded agent runtime

Prerequisite: [Week 6 gate](../../assessments/weekly/week-06.md). This week
turns model proposals into controlled execution: fixed workflows and state
machines, typed tool capabilities, a validated decision loop, dependency-aware
scheduling, explicit budgets, and trace-driven recovery.

| Day | Chapter | Lab artifact |
|---|---|---|
| 1 / D37 | [Workflows, agents, and state machines](day-01/README.md) | Explicit routing and terminal state |
| 2 / D38 | [Typed tools and schemas](day-02/README.md) | Closed-schema validation |
| 3 / D39 | [Decision-observation loop](day-03/README.md) | Deterministic custom loop |
| 4 / D40 | [Sequential and parallel tools](day-04/README.md) | Topological layers |
| 5 / D41 | [Budgets and cancellation](day-05/README.md) | Post-call reconciliation |
| 6 / D42 | [Recovery, traces, and evaluation](day-06/README.md) | Redacted trace summary |

Work through the [six labs](../../labs/week-07/README.md), then complete the
[weekly assessment](../../assessments/weekly/week-07.md) before consulting its
[separate answer guide](../../solutions/examinations/week-07.md). The reference
runtime is documented in [ForgeAgent](../../projects/agent-runtime/README.md).
Examples and checks use deterministic fake providers, so normal study requires
no credentials or network calls.
