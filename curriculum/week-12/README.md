# Week 12 — ForgeAgent capstone

Prerequisites are the [Week 11 service and deployment exam](../../assessments/weekly/week-11.md)
and the [Phase 5 reliability gate](../../assessments/phase-examinations/phase-05.md).
Across D67–72, assemble a small coding agent from the repository's runtime,
policy, context, durability, MCP, evaluation, and service components. The capstone
is an engineering exercise in constrained delegation. It is not a claim that an
offline scripted provider demonstrates general coding ability.

| Day | Chapter | Independent artifact |
|---|---|---|
| D67 | [Repository tools and system boundary](day-01/README.md) | A bounded, read-only code index |
| D68 | [Plans, trajectories, and verification](day-02/README.md) | A validated inspect/propose/check trace |
| D69 | [Patch proposals and human authority](day-03/README.md) | One-use content-hash approval path |
| D70 | [Execution isolation and cancellation](day-04/README.md) | An injected test backend with fail-closed behavior |
| D71 | [Context, checkpoints, and resume](day-05/README.md) | A compact, revisioned resumable session |
| D72 | [Evaluation and technical defense](day-06/README.md) | A fixed development/held-out report and design defense |

Work independently in [the labs](../../labs/week-12/README.md), use the [weekly review](weekly-review.md) and
[weekly examination](../../assessments/weekly/week-12.md), and prepare for the
[Phase 6 defense](../../assessments/phase-examinations/phase-06.md) and
[final examination](../../assessments/final/README.md). Expected effort is
45–60 hours. No paid model, live account, container daemon, or GPU is required
for the core exercises. Testing proposed code requires an explicitly supplied
isolation backend; the default deliberately refuses execution.
