# Week 2 — Software engineering and mathematical foundations

Build an owner-scoped asynchronous document API and the mathematical routines
needed for neural computation. This continues the same ForgeAgent package;
it does not introduce a separate agent framework or claim a production service.
Prerequisite: [Week 1 gate](../../assessments/weekly/week-01.md).

| Local day / global ID | Separate document | Independent artifact |
|---|---|---|
| 1 / D07 | [HTTP, JSON, and trust](day-01/README.md) | Strict document validator |
| 2 / D08 | [SQLite and transactions](day-02/README.md) | Persistent owner-scoped store |
| 3 / D09 | [Processes, threads, async I/O](day-03/README.md) | Structured concurrent collector |
| 4 / D10 | [Timeouts, retries, cancellation](day-04/README.md) | Selective bounded retry |
| 5 / D11 | [Vectors, matrices, probability](day-05/README.md) | Shape-checked arithmetic |
| 6 / D12 | [Derivatives, logs, optimization](day-06/README.md) | Stable softmax and gradient checks |

Use [labs](../../labs/week-02/README.md) for contracts and graduated hints;
[solutions](../../solutions/labs/week-02/explanation.md) remain separate.
Finish [weekly review](weekly-review.md), the [weekly exam](../../assessments/weekly/week-02.md),
and [Phase 1 examination](../../assessments/phase-examinations/phase-01.md).
Budget 42–54 instructional hours plus review; add 1–2 weeks for math or concurrency
remediation if gates fail. Full beginner mastery within six days is not promised.

The [local API demonstration](../../projects/storage-api/README.md) is a bounded
learning transport. Ordinary tests are offline/in-process. A local socket smoke
test checks actual transport separately. Week 3 remains planned.
