# Week 3 — Machine learning and neural networks

Prerequisite: [Phase 1 gate](../../assessments/phase-examinations/phase-01.md).
The objective is to implement and explain learning mechanisms before using
model APIs, not to become a model-scale training specialist.

| Day | Chapter | Independent implementation |
|---|---|---|
| 1 / D13 | [Data and inference](day-01/README.md) | Reproducible partitions |
| 2 / D14 | [Loss and updates](day-02/README.md) | Analytic regression step |

| 4 / D16 | [Mini-autograd](day-04/README.md) | Shared-path reverse mode |
| 5 / D17 | [Training and generalization](day-05/README.md) | Optimizer and fresh-graph training |
| 6 / D18 | [Character language model](day-06/README.md) | Smoothed conditional counts |

Use the [labs](../../labs/week-03/README.md), then [review](weekly-review.md) and
[weekly exam](../../assessments/weekly/week-03.md). References remain separate.
Budget 42–54 focused hours; add days for graph/gradient remediation. All examples
are small CPU computations using the standard library; no GPU or framework is
required. The [micro-project](../../projects/mini-autograd/README.md) is supporting
instruction, while ForgeAgent remains the evolving primary application project.
