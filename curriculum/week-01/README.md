# Week 1 — Python and programming foundations

Outcome: independently build, debug, test, and explain a local document-search
CLI. This is milestone 1 of ForgeAgent, not yet an AI agent. No prior programming
is assumed. Use a CPU laptop; no dependencies, GPU, or paid API are required.
Budget 42–54 focused instructional hours plus a review day; extend if needed.

| Day | Chapter | Independent artifact |
|---|---|---|
| 1 / D01 | [Programs, values, execution](day-01/README.md) | Text summary |
| 2 / D02 | [Decisions and repetition](day-02/README.md) | Explicit normalizer |
| 3 / D03 | [Functions and collections](day-03/README.md) | Fresh token counter |
| 4 / D04 | [Files, exceptions, modules](day-04/README.md) | Sorted UTF-8 loader |
| 5 / D05 | [Objects, types, debugging, tests](day-05/README.md) | Deterministic hit ranking |
| 6 / D06 | [Git, complexity, integration](day-06/README.md) | Tested JSON CLI |
| Review | [Retention and remediation](weekly-review.md) | Weekly exam and corrected failures |

Follow chapters in this order. Each links a [lab contract](../../labs/week-01/README.md),
exam questions, and the next chapter. Try without solutions, then test, debug,
and explain. The [weekly examination](../../assessments/weekly/week-01.md)
measures conceptual, coding, debugging, and architecture competence.
[Progress tracking](../../PROGRESS_TRACKER.md) records evidence and delayed recall.

Before Week 2, demonstrate a stable process contract, fresh function state,
correct empty-input behavior, and visible malformed-file failures. If you cannot,
use the review's focused remediation. Continue with [Week 2](../week-02/README.md) after passing the gate.
