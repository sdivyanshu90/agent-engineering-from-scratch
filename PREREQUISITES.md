# Prerequisites and preparation

No prior programming, calculus, networking, or AI knowledge is assumed. You need
a computer on which you can create files, a keyboard, a terminal, and enough
time for sustained practice. [Setup](START_HERE.md) explains tools. Day 1 explains
working directories, processes, values, and the first counting exercise.

Before Day 1 verify that you can find a saved file in the editor, run a command
from its directory, and read output. If these are unfamiliar, repeat the setup
walkthrough and compare the file listing with the repository root. Nothing
requires an account, API key, cloud machine, or GPU in Week 1.

Before Week 2 demonstrate Week 1's gate, then learn JSON/HTTP/SQL and vectors in
that week's planned sequence. Before machine learning, probability and derivatives
must be taught, traced, and implemented. Before attention, matrix shapes and
cross-entropy must be established. Before an agent loop, function boundaries,
validation, and error propagation must be reliable. The
[dependency graph](CONCEPT_DEPENDENCY_GRAPH.md) makes this ordering explicit.

Experienced learners may attempt the [diagnostic](assessments/diagnostic/README.md).
A failed diagnostic is an entry-point recommendation, not an exclusion criterion.
No prerequisite can be considered taught merely because a title appears in the
planned schedule. Later prerequisite remediation chapters are outstanding work.
