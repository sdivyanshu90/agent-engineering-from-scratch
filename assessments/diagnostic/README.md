# Entry diagnostic: determine where to begin

No time pressure is required. Attempt without reference solutions or generated
code. Complete beginners can begin Day 1 directly; this diagnostic is for learners
seeking to skip already-mastered material.

1. Predict `x=2; y=x+1; x=8`: give both final values and explain why y does not change.
2. Predict list aliasing after `a=[]; b=a; b.append('x')`. Explain mutation versus rebinding.
3. Write a fresh-state token frequency function; test empty input and two calls.
4. Read sorted immediate UTF-8 `.txt` files from a temporary directory. Demonstrate an invalid-encoding failure without hiding it.
5. Write a test detecting incorrect tie ordering in frequency-ranked results.
6. Build a CLI producing one JSON payload on success and a nonzero status on failure; show both streams from a subprocess.

Award 0 (incorrect/missing), 1 (correct answer with incomplete explanation), or
2 (correct independent result plus mechanism and boundary case) for each task.
Suggested entry: task 1 incomplete → Day 1; task 2 incomplete → Day 2; task 3
incomplete → Day 3; task 4 incomplete → Day 4; task 5 incomplete → Day 5; task 6
incomplete → Day 6. A later successful task does not waive an earlier failed one.
To skip all Week 1, require 12/12 and the [weekly exam](../weekly/week-01.md) gate.

Assess after saving your attempt using [reference criteria](../../solutions/examinations/week-01.md).
The diagnostic assesses only the authored Week 1; it cannot justify skipping
Week 2 or later weeks. Its scoring is a curriculum device, not a validated psychometric test.
