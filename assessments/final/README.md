# Final examination — engineering the bounded agent

Complete after [Phase 6](../phase-examinations/phase-06.md). The final is an
artifact review and oral defense, not a model demonstration. Submit the
capstone source, fixed benchmark reports, trajectory traces, failure analysis,
and a concise limitations register. The [reference rubric](../../solutions/examinations/final.md)
lists required evidence.

## Required defense sequence

1. Trace one read-only request from schema validation to untrusted observation.
2. Trace one exact patch proposal through human review, one-use apply, and test
   evidence tied to the resulting revision.
3. Demonstrate stale-source and unauthorized-approval refusal.
4. Restart a pending workflow and reconcile any uncertain effect.
5. Show fixed development and held-out benchmark rows with denominators.
6. State what was not measured and identify a concrete next experiment.

Pass requires 80/100 and all critical safety boundaries. A scripted offline
provider is acceptable for deterministic protocol evidence, but it is not
evidence of autonomous real-model coding ability. An injected recording backend
is acceptable for adapter contract evidence, but it is not evidence that a
production sandbox contains malicious code.
