# Pedagogical rationale

Predict before executing to expose a model of causality rather than familiarity.
Alternate a small worked example with an independent implementation to reduce
the temptation to copy a complete project. Keep solutions separate and require
changed-input reconstruction after consulting them. Delay extra abstraction
until the learner can explain what it replaces.

Prerequisite gates create a route through the material. A trace checks worked
understanding; a contract implementation checks construction; a deliberately
broken variant checks debugging. Design questions require a concrete alternative
and evidence, not preferences. Spaced recall checks retention after a delay.
These are educational design choices; no measured efficacy study of this new
repository has been conducted.

The machine validator detects missing sections/links/contracts, not readability,
conceptual rigor, originality, or mathematical truth. A separate manual author
review is recorded in [the completion audit](completion-audit.md). Independent
beginner usability review and external technical review remain outstanding.
