# Week 9 assessment answer key

1. Client launches the server process and sends JSON-RPC `initialize` with request ID 1 and `protocolVersion: "2025-11-25"`; server replies with the same ID and negotiated version/capabilities/serverInfo. Client then sends `notifications/initialized` without an ID. It calls `tools/list` (ID 2), then `tools/call` (ID 3 with name and arguments). The result contains content parts and `isError`. If a different version is returned, this pinned client closes and refuses normal operation. Stdio is newline-delimited UTF-8 JSON-RPC; this is not HTTP.
2. Only `echo` is visible because the exposed set is server-advertised ∩ host-supported ∩ session-policy allowed. The advertisement describes what the server can do. It does not establish user consent or the host’s authorization decision.
3. The current file digest no longer equals `h1`, so the optimistic-concurrency check rejects the write even though the user previously approved. Changed arguments also fail because approval was bound to the original exact arguments. The proposal cannot be reused with a different path, session, tool, or revision, and successful application consumes it once.
4. The required fields are `name` and `description`; the name has format/length/directory-name constraints and the description is nonempty and bounded. The loader parses bounded text and returns a body marked untrusted. It must not execute the prose, promote it to system authority, or enlarge the tool allowlist. A separately loaded reference remains untrusted; delaying its load controls context size, not provenance.
5. MCP tools/call is a host-to-server operation with a direct request/result in the subset studied. A2A uses agent discovery through an Agent Card and can represent asynchronous tasks. Operations include `Get Task` and `Subscribe to Task` (also `Cancel Task`); artifacts may arrive after submission. Remote endpoint identity/authentication and untrusted returned artifacts are additional boundaries.
6. No. A normal child process usually inherits the parent’s OS identity and access; timeout limits duration, not filesystem or network authority. With no explicit isolation backend, `TestExecutor` denies and runs nothing. Path normalization does not stop a concurrent attacker from swapping a checked directory for a symlink between check and open/write; stable-root checks are not race-proof sandboxing.

## Scoring notes

Award reasoning credit for equivalent precise formulations. A response claiming MCP alone enforces consent, a skill body grants shell access, a hash proves approver identity, a subprocess is a sandbox, or a path check is race-proof triggers a critical misconception; remediate before passing.
